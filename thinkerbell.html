Task
Edit object or camera motion in a source video to follow target motion while preserving source content.
Input → Output
Input
  • Source video: the clip to edit.
  • Source point tracks: point positions and visibility tracked in the source video.
  • Target point tracks: the desired motion of the same points.
  • Editing instruction: how the source motion should change.
  • Target caption: a description of the edited video.
Output

An edited video with the requested motion.

Our idea
A separate reasoner interprets the tracks in the context of the source video and editing intent. The generator then synthesizes the edited video using that understanding.
Reading the tracks
  • Matching colors identify the same point.
  • Target track panels show paths up to the current frame.
  • Overlays show the last 10 frames of each path.
  • If a dot is not shown, the region containing that point is not visible.

Method

Understand the tracks first, then generate

The Vision-Language-Track (VLT) reasoner understands the tracks in the context of the source video and the editing intent. A learnable coupling transfers this understanding to the generator, which synthesizes the edited video.

1VLT: Understanding Tracks in Context

VLT learns representations that connect the tracks to the source scene and to the editing instruction through a curriculum of 1.9M track-understanding questions: (1) which object or camera the tracks follow, (2) what motion they express, and (3) whether the change from source to target tracks carries out the requested edit.

These tasks teach one shared VLT to relate track geometry to the source scene and the requested change.

Benchmark

Benchmark for Track-Conditioned Video Motion Editing

The benchmark is split by motion type into four categories, each with 100 real source–target video pairs: joint object–camera (Koala-36M), object only (RH20T), camera only in a dynamic scene (Harmony4D) and camera only in a static scene (DL3DV-10K).

Source–target point correspondences come from tracking across clips or calibrated cross-view matching. Two example pairs are shown for each category.
